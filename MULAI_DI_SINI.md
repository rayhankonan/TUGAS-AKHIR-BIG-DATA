# Mulai di sini

1. Baca `reports/laporan_akhir.pdf` untuk masalah, metode, angka hasil, grafik, validasi, performa, rekomendasi, dan keterbatasan.
2. Tiga notebook pada `notebooks/` sudah memiliki hasil eksekusi. Buka berurutan dari 01 sampai 03.
3. Bukti hasil ada di `output/`: agregasi, Parquet, tiga grafik, laporan validasi, audit PostgreSQL, dan benchmark tiga skala.
4. Untuk demonstrasi ulang, ikuti README.md. Folder lengkap memiliki runtime Java/PostgreSQL portabel; arsip ZIP pengumpulan mengecualikan runtime dan database aktif.
5. Isi `IDENTITAS_KELOMPOK.md` sebelum mengumpulkan. Pelajari `reports/outline_presentasi.md` dan `reports/checklist_rubrik.md` untuk persiapan menjelaskan pekerjaan.

Data bersifat sintetis. Jangan mengganti hasil dengan angka bisnis nyata tanpa menjalankan ulang seluruh tahap.
